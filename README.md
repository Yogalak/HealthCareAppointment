🏥 Healthcare Appointment & Prescription Management System

A scalable backend system built using Django REST Framework (DRF) to streamline healthcare operations such as appointment scheduling, prescription management, and role-based access control.

Designed with production-level architecture, this project demonstrates expertise in API development, authentication, background processing, and database optimization.

📌 Project Highlights (ATS Keywords)
Built RESTful APIs using Django REST Framework (DRF)
Implemented JWT Authentication for secure user access
Designed role-based access control (RBAC) for Admin, Doctor, and Patient
Integrated Celery + Redis for asynchronous background tasks
Used Django Signals for event-driven notifications
Optimized database queries using select_related & prefetch_related
Implemented rate limiting and secure API handling
Developed scalable and modular backend architecture
